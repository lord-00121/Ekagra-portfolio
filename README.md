# Ekagra Ramola — Developer Portfolio

A responsive, one-page developer portfolio built with HTML, CSS, and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `ekagra-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` from this folder (you can also upload `README.md`).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the published link to appear. It will usually look like `https://lord-00121.github.io/ekagra-portfolio/`.

## Before sharing
- Confirm all project descriptions and links are accurate.
- Add a direct repository link for the AI Document Assistant if it has its own public repository.
- If you prefer, change the repository name and adjust the published URL accordingly.
